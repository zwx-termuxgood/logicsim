## 目标与执行门槛

彻底统一连线几何与电气判断为整数网格运算，修复正交折线缩短、选中线路移动残留/斜线，以及连接点绘制与实际连通不一致的问题。参考所提供的 Logisim Java 代码的整数位置、端点连接、线段裁剪和节点绘制语义，保持本项目现有架构和中文注释风格，不直接移植 Java 仿真体系。

**本轮仅做方案审阅；批准后先 Git 备份，核验备份成功后才改代码。**

## 已发现的问题

- `WireNetworkSolver.cpp` 使用取整后的字符串位置键，同时又用 `0.5` 浮点容差判断在线段上，两种位置语义不一致。
- `Circuit_wire.cpp::shortenWireEnd` 用到两端的直线距离猜测缩短端，并重新生成 L 形路径，未沿原折线裁剪，因此多拐点路径会丢失或缩短错误。
- `Circuit.h` 当前缩短接口已有 `shrinkFront` 参数，但实现和 JS 调用仍为旧接口，需要统一。
- `moveSelection` 只识别元件，只有线被选中时会提前退出；元件随动逻辑也存在浮点方向判断。前端选择、模型移动、线段随动需要完整打通。
- `CanvasInteraction.js`、`CanvasView.qml`、`ClipboardCodec.cpp`、`MoveGesture.cpp` 等保留重复的浮点拓扑判断。
- 端口几何存在按元件尺寸分配的小数偏移，必须同步处理，否则单独将导线取整仍会出现画面端口与电气位置不一致。
- 当前已有未提交修改：`src/app/main.cpp`、`src/core/CMakeLists.txt`、`src/model/Circuit.h`，新增 `src/core/Grid.h`，以及 `output.txt` 删除；已有历史 tag/stash 不能代替本次操作前完整备份。

## 2. 建立唯一整数网格几何基础

**涉及：** `src/core/Grid.h`、`src/core/CMakeLists.txt`、`src/logic/ComponentLogic.cpp` 及必要的端口绘制调用处。

- 在现有未跟踪 `Grid.h` 基础上审查完善，而非另建一套互相竞争的工具。
- 区分世界拓扑坐标和屏幕坐标：持久化位置、端口世界位置、折线顶点、拓扑键均为整数；鼠标、缩放和平移可使用浮点，仅在交互边界转换一次。
- 自由绘线与移动采用项目的 **10px 吸附网格**；已有元件端口/线所在行列使用统一的精确整数位置，不将已吸附的端口坐标再强行吸附到另一条行列。
- 端口偏移的离散化在统一几何来源完成，绘制、命中、绑定、求解使用相同结果，不能仅在求解时偷偷取整。兼容当前布局中不位于 10px 倍数的端口。
- 提供整数点/位置键、正交段包含、内部包含、投影、路径裁剪与规范化等共享函数；拓扑判断不再使用 epsilon、`0.5` 或距离近似。
- 检查有限值、坐标范围及距离运算溢出；负坐标采用明确一致的取整规则。
- 路径规范化去重、去零长段、消除无意义共线点，但不得跨越必须保留的连接语义；禁止用随意补一个拐点掩盖移动算法产生的非法路径。

## 3. 电气连通和连接点绘制共用拓扑

**涉及：** `src/logic/WireNetworkSolver.{h,cpp}`、`src/model/impl/Circuit_wire.cpp`、`qml/views/canvas/CanvasView.qml`、`qml/views/canvas/Painter.js`。

- 以整数正交线段建立连接关系，保持用户线路 ID/整条折线身份，不因拓扑内部拆段使选择移动失去整体性。
- 对照 Logisim `CircuitWires.connectWires` 的端点合并方式，对 T 接入和端口接入建立等价拆分节点。
- 明确规则：端点重合相连；端点/端口接入线段相连；共线重叠按同一导体处理；纯粹的两段内部十字穿越不因几何相交就自动相连。折点作为实际线段端点参与判断，不能只检查整条 path 首尾。
- 在十字交点存在明确端点、支路或端口接入时，按实际节点关系处理，不能机械地把所有十字都判为不连。
- 电气网络和圆点从同一拓扑得出，按有效支路/端口计数，排除重复段造成的虚假圆点。
- 与提供的 Logisim 画法对齐：普通直通与两段拐角不画连接圆点，T/明确多路连接画实心圆点；纯穿越不画圆点，不擅自新增跨线桥样式。
- 保持现有非正交线型/虚拟线接口兼容，避免改变原有仿真引擎职责。

## 4. 按原路径修复缩短

**涉及：** `src/model/Circuit.h`、`src/model/impl/Circuit_wire.cpp`、`qml/views/canvas/interactions/CanvasInteraction.js`、必要的 `qml/Main.qml` 状态。

- 统一声明、实现和 QML 调用，手势开始时记录实际操作的前端/后端，不再用欧氏距离猜端。
- 将鼠标目标吸附到原路径的精确整数段上，并明确命中段索引；沿原 path 截去指定端到目标之间的部分，完整保留另一侧所有原有拐点。
- 支持直线、L 形、多拐点、反向路径、目标位于拐点以及完全缩为空；目标不在原路径时不错误重建线路。
- 仅清除被裁剪端失效的端口绑定，保留另一端及仍成立的连接关系。
- 成功修改才产生撤销记录；一次缩短手势保持一致的撤销/重做行为。

## 5. 修复选中线路整体移动与外部随动

**涉及：** `src/model/impl/Circuit_component.cpp`、`src/model/Circuit.h`、`qml/views/canvas/interactions/CanvasInteraction.js`、`qml/Main.qml`；对 `src/move/MoveGesture.cpp`、`Connector.cpp` 中涉及的拓扑判定同步统一。

- 选择集合明确区分元件 ID 与线路 ID，支持仅选线和元件/线路混合选择；命中一条折线后，移动该线路的全部顶点，而不是只改某一段或端点。
- 每次手势以开始时的整数几何快照和累计整数位移计算新位置，避免逐帧增量取整累积漂移。
- 选中线全部顶点采用相同位移，只变换一次；同时选中端点元件时避免随动逻辑重复移动。
- 明确区分显式选中的整线平移、两端元件同移的整线随动、只有一端移动的外部接线正交调整。未选中的远端保持固定，按原方向重建必要的正交接续，不能直接拉出斜线。
- 整线移离原端口时清理失效绑定；混合移动时保留仍有效的绑定，防止遗留绑定使线路被求解器错误连接回原位置。
- 固定分支的处理依据移动前真实节点关系；不把整个电气网络无条件移动，也不留下本应随选中折线移动的旧段。
- 拖动预览与最终提交使用同一规则，提交后检查整数、轴对齐、无重复旧线段；撤销/重做完整恢复几何与绑定。

## 6. 堵住其他浮点入口与旧数据兼容

**涉及：** `src/io/ClipboardCodec.cpp`、`src/io/JsonCodec.cpp`、必要的模型加载/粘贴入口。

- 复制、粘贴、保存、加载、撤销恢复均遵守相同的整数几何约定，不保留另一套浮点 T 接入判定。
- 旧数据在明确边界一次性转换为整数，保留 ID、端口关系及合法正交走向，不在每次求解时反复四舍五入。
- 对旧数据已有斜段制定确定的正交迁移规则并加测试；新编辑流程禁止生成斜段。无效/越界数据不得静默产生错误连通。
- 复用现有逐段中文解释、头文件说明与命名风格；注释重点说明网格约束、连接规则及为何不能使用浮点容差。
