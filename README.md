LogicSim

一个基于 Qt 6 / QML 的数字逻辑电路模拟器，支持多比特位宽、子电路嵌套、事件驱动仿真、晶体管级建模，可运行于桌面端与 Android。

本项目代码主要由 AI 辅助生成，作者进行了调试与优化。
仅供学习、实验与个人使用，请勿用于对可靠性有严格要求的场景。
需要专业电路仿真请使用 Logisim-evolution。

---

为什么做这个

Logisim 很好用，但它跑不了移动端。小屏幕上按 Logisim 那种"拖一整条线"的方式操作也很别扭。

所以这个项目在交互上做了取舍：拉线是按下—拖动—释放的手势，松开时按当前生效线型（贝塞尔 / 正交）落线。正交线还支持从已有线中间 T 型引出、拖动时切换拐角方向、拖回原线内部时缩短原线而不是新建。屏幕再小也不怕。

功能上尽量向 Logisim 看齐，操作上尽量为触屏和小屏优化。做了不少取舍，可能还有不少问题，但日常搭个小电路玩玩是够的。

---

两个仿真引擎

项目内置两套引擎，可在设置里切换：

事件驱动引擎（新，默认）

· 有时间概念，时间只随事件推进
· 支持门延迟、导线延迟，可按门类型单独配置延迟
· 振荡电路能跑起来，而且永远跑不完——这才是真实电路的样子
· 适合时序电路、振荡器、延迟敏感的场景
· 必须手动"开始仿真"，未开始时输入和时钟不传播

迭代引擎（旧）

· 没有时间概念，一次性求值到收敛
· 组合逻辑按拓扑排序，环路迭代有限次
· 简单直接，适合纯组合电路

核心特性

电路建模

· 多比特位宽，1 ~ 64 位
· 多种显示进制：二进制 / 无符号十进制 / 有符号十进制 / 十六进制 / 单精度浮点 / 双精度浮点
· 完整逻辑门库：AND / OR / NOT / NAND / NOR / XOR / XNOR
· 晶体管级：传输门、NMOS、PMOS，支持高阻态
· 分线器 / 集线器：可配置分段，做位拼接与位拆分
· 子电路：自定义、嵌套调用、循环引用检测、设为主电路、只读浏览、端口自动同步
· 时钟：频率可调，支持运行 / 停止 / 单步 / 复位
· 多驱冲突自动解析为错误态

交互

· 三种模式：编辑 / 控制 / 选择
· 编辑模式：放置、拖动、连线、旋转、改属性
· 控制模式：点击开关翻转、点击时钟翻转
· 选择模式：框选、多选、复制、粘贴、批量删除
· 画布：滚轮缩放，空白处拖动平移
· 端口圆点实时反映信号状态，连线颜色跟着变
· 连线类型：贝塞尔 / 正交 / 可切换（顶部栏切换，设置页可选全局模式）
· 正交线编辑：可拖中间拐点（相邻拐点联动保持正交）、可从线中间 T 型引出、可缩短原线
· 移动元件自动重连线：A* 避让寻路，独立线程计算，不卡 UI
· 视图导航：视野内无元件时出现导航指示器，点击跳到最近元件

工程

· 撤销 / 重做，连续操作自动合并
· 位宽检查：连线两端不匹配时自动报错
· JSON 存档（version 11），兼容旧文件；加载时容错提取首个完整 JSON 对象并回写修复
· 导入外部电路：加前缀避免 ID 冲突，支持重复导入（先卸载旧导入）、取消导入
· 最近文件列表
· 电路统计（递归含子电路）
· 桌面端 + Android 跨平台

界面说明

菜单：保存、另存为、打开、导入…、已导入…、最近、统计、新建、设置

顶部栏：菜单、模式切换（编辑/控制/选择）、线型切换（可切换模式下显示）、撤销/重做、缩放（缩小/百分比/放大）、上下文选择器、未保存标记、收起

时钟栏：仿真控制（开始/暂停/单步/复位，仅事件引擎）、时钟控制（启停/时钟拍/复位输入/频率）、仿真时间与拍数显示

左侧面板

· 元件面板：按分组列出所有元件（输入输出 / 基本逻辑门 / 复合逻辑门 / 传输门·晶体管 / 工具 / 控制），以及子电路列表（右键或长按菜单：选中、重命名、设为主电路、删除）
· 属性面板：多选操作（复制/粘贴/删除）、元件属性（名称、方向、位宽、输入数、显示进制、门延迟、LED 颜色、分线器分段、文本内容）、连线属性、子电路属性、错误列表
· 错误列表：位宽不匹配等问题

画布

· 放置元件：左侧选中类型 → 点击画布
· 拖动元件：编辑模式下直接拖；选择模式下可框选后批量拖动
· 连线：按下端口圆点 → 拖动 → 释放到目标端口
· 正交线：可从已有线中间 T 型引出；拖回原线内部会缩短原线
· 框选：选择模式空白处拖动
· 进入子电路：双击子电路实例
· 缩放 / 平移：滚轮缩放、空白处拖动
· 导航：视野内无元件时显示指示器，点击跳最近元件

状态栏：当前模式、状态提示、错误数

设置页：仿真引擎选择、连线模式（贝塞尔/正交/可切换）、传播延迟（门延迟/导线延迟，仅事件引擎）、仿真速度（自动/指数）、显示仿真时间

构建

依赖

· Qt 6.5+（Quick / QuickControls2 / Qml）
· CMake 3.16+
· C++17 编译器

桌面端

```bash
git clone https://github.com/zwx-termuxgood/logicsim.git
cd logicsim
mkdir build && cd build
cmake ..
cmake --build . -j4
./LogicSim
```

Windows 交叉编译（MXE）

⚠ 此脚本在作者环境之外基本无法直接运行，需要自行配置 MXE 工具链。

```bash
chmod +x qtWin.sh
./qtWin.sh
```

Android

用 Qt Creator 打开 CMakeLists.txt，选择 Android Kit 构建部署。

项目结构

```
logicsim/
├── circuit/              # C++ 核心
│   ├── Circuit.h/.cpp    # 模型主类：Q_PROPERTY + Q_INVOKABLE + 信号
│   ├── core/             # CircuitContext、Component/Wire 存取器、ID 分配、
│   │                     # UndoData（撤销快照/栈）、ValueCodec（进制编解码）
│   ├── logic/
│   │   ├── ComponentLogic.*        # 元件知识唯一入口：端口数量/位宽/几何/组合逻辑
│   │   ├── WireNetworkSolver.*     # 虚拟线（电气网络）、连接圆点
│   │   ├── SimEngine.h             # EngineKind 枚举与字符串互转
│   │   ├── event/                  # 事件驱动引擎：build / run / trigger
│   │   ├── iter/                   # 迭代引擎：evalOne / evaluateContext / evaluateAll
│   │   └── move/                   # 移动重连线：A*、避让网格、独立线程
│   ├── io/
│   │   ├── JsonCodec.*             # 存档编解码（version 11）
│   │   ├── ClipboardCodec.*        # 复制/粘贴编解码
│   │   └── RecentStore.*           # 最近文件（QSettings + JSON）
│   └── app/                        # Circuit 分部实现
│       ├── Circuit_catalog.cpp     # 静态转发到 ComponentLogic
│       ├── Circuit_component.cpp   # 增删改元件、移动、属性
│       ├── Circuit_wire.cpp        # 增删改连线、命中测试、T 型、缩短
│       ├── Circuit_subcircuit.cpp  # 子电路增删、进入/退出、设为主电路
│       ├── Circuit_simulation.cpp  # 时钟、仿真、门延迟
│       ├── Circuit_selection.cpp   # 复制/粘贴
│       ├── Circuit_query.cpp       # 查询、格式化、统计
│       └── Circuit_lifecycle.cpp   # 引擎切换、求值、文档、撤销、最近文件
├── qml/                  # QML 前端
│   ├── Main.qml          # 主窗口：模型实例、视图状态、缓存、快捷键、布局
│   ├── Theme.qml         # 主题单例（颜色/尺寸/字号）
│   └── views/
│       ├── bars/         # TopBar / ClockBar / StatusBar
│       ├── canvas/       # CanvasView + Geometry.js / Painter.js + interactions/
│       ├── panels/       # LeftPanel / PropertyPanel / SubcircuitPanel / props/
│       └── dialogs/      # 各类对话框与弹窗
├── android/              # Android 打包资源（图标 + AndroidManifest.xml）
├── main.cpp              # 入口：注册 Circuit、加载 Main
├── CMakeLists.txt        # 构建脚本
├── qtWin.sh              # MXE 交叉编译脚本（未广泛验证）
├── map.md                # 项目结构详细说明
└── README.md
```

分层：

· 数据层：元件与连线统一用 QVariantMap，上下文用 CircuitContext，全部值语义可拷贝（撤销/导入/粘贴依赖此特性）
· 逻辑层：ComponentLogic 是元件规则的唯一事实来源；WireNetworkSolver 把几何连线转成电气网络；两套引擎都基于前两者，保证行为一致
· 模型层：Circuit 聚合所有状态，通过信号与 Q_INVOKABLE 对 QML 暴露
· 视图层：QML 通过 circuitRef 读写模型，Canvas 自绘全部图形，交互集中在 CanvasInteraction.js
· 移动重连：move/ 用 A* 在避让网格上重新规划连线，运行在独立线程 ConnectorThread，结果缓存在 MoveGesture

---

已知限制

· 事件引擎需要手动"开始仿真"，未开始时输入和时钟不传播
· 振荡电路在事件引擎下会持续占用事件预算，受预算上限约束
· 移动重连线在连接数较多时可能超时（10 秒上限），未满足的连接会记录在 MoveResult::unsatisfied 中
· 事件引擎单次 run 有事件数预算（默认 200000），超大电路一次推进不完需要多次 run
· Windows 交叉编译脚本未在作者之外的环境验证
· 深层嵌套子电路可能存在性能问题（递归深度保护上限 32 层）
