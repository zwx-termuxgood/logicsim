# LogicSim

一个基于 Qt 6 / QML 的**数字逻辑电路模拟器**，支持多比特位宽、子电路嵌套、事件驱动仿真、晶体管级建模，可运行于桌面端与 Android。

> 本项目代码主要由 AI 辅助生成，作者进行了调试与优化。
> 仅供学习、实验与个人使用，**请勿用于对可靠性有严格要求的场景**。
> 需要专业电路仿真请使用 [Logisim-evolution](https://github.com/logisim-evolution/logisim-evolution)。

---

## 为什么做这个

Logisim 很好用，但它跑不了移动端。小屏幕上按 Logisim 那种"拖一整条线"的方式操作也很别扭。

所以这个项目换了个思路：**连线改成点对点**——点一下源端口，再点一下目标端口就完成连接。屏幕再小也不怕。

功能上尽量向 Logisim 看齐，操作上尽量为触屏和小屏优化。做了不少取舍，可能还有不少问题，但日常搭个小电路玩玩是够的。

---

## 两个仿真引擎

项目内置两套引擎，可在设置里切换：

**事件驱动引擎（新，默认）**
- 有时间概念，时间只随事件推进
- 支持门延迟、导线延迟，可按门类型单独配置
- 振荡电路能跑起来，而且永远跑不完——这才是真实电路的样子
- 适合时序电路、振荡器、延迟敏感的场景

**迭代引擎（旧）**
- 没有时间概念，一次性求值到收敛
- 组合逻辑按拓扑排序，环路迭代有限次
- 简单直接，适合纯组合电路

## 核心特性

**电路建模**
- 多比特位宽，1 ~ 64 位
- 多种显示进制：二进制 / 无符号十进制 / 有符号十进制 / 十六进制 / 单精度浮点 / 双精度浮点
- 完整逻辑门库：AND / OR / NOT / NAND / NOR / XOR / XNOR
- 晶体管级：传输门、NMOS、PMOS，支持高阻态
- 分线器 / 集线器：可配置分段，做位拼接与位拆分
- 子电路：自定义、嵌套调用、循环引用检测、设为主电路、只读浏览、端口自动同步
- 时钟：频率可调，支持运行 / 停止 / 单步 / 复位
- 多驱冲突自动解析为错误态

**交互**
- 三种模式：编辑 / 控制 / 选择
- 编辑模式：放置、拖动、连线、旋转、改属性
- 控制模式：点击开关翻转、点击时钟翻转
- 选择模式：框选、多选、复制、粘贴、批量删除
- 画布：滚轮缩放，空白处拖动平移
- 端口圆点实时反映信号状态，连线颜色也跟着变

**工程**
- 撤销 / 重做，连续操作自动合并
- 位宽检查：连线两端不匹配时自动报错
- JSON 存档，兼容旧文件
- 桌面端 + Android 跨平台

## 界面说明

**菜单**：保存、另存为、打开、最近文件、统计、新建、设置

**顶部栏**：菜单、模式切换、撤销/重做、缩放、上下文选择器、折叠

**时钟栏**：仿真控制（开始/暂停/单步/复位）、时钟控制（启停/单步/复位输入/频率）、仿真时间与拍数显示

**左侧面板**
- 元件面板：分类列出所有元件，以及子电路列表
- 属性面板：选中元件的全部可调属性
- 错误列表：位宽不匹配等问题

**画布**
- 放置元件：左侧选中类型 → 点击画布
- 拖动元件：编辑模式下直接拖
- 连线：点端口圆点 → 点目标端口
- 框选：选择模式空白处拖动
- 进入子电路：双击子电路实例
- 缩放 / 平移：滚轮缩放、空白处拖动

**状态栏**：当前模式、状态提示、错误数

## 支持的元件

| 分类 | 元件 |
|------|------|
| 输入输出 | 输入开关、常量、输出端口、LED |

## 构建

**依赖**
- Qt 6（Core / Gui / Qml / Quick / QuickControls2）
- CMake 3.16+
- C++17 编译器

**桌面端**

```bash
git clone https://github.com/zwx-termuxgood/logicsim.git
cd logicsim
mkdir build && cd build
cmake ..
cmake --build . -j4
./LogicSim
```

**Windows 交叉编译（MXE）**

> ⚠ 此脚本在作者环境之外基本无法直接运行，需要自行配置 MXE 工具链。

```bash
chmod +x qtWin.sh
./qtWin.sh
```

**Android**

用 Qt Creator 打开 `CMakeLists.txt`，选择 Android Kit 构建部署。

## 已知限制

- 事件引擎需要手动"开始仿真"，未开始时输入和时钟不传播
- 振荡电路在事件引擎下会持续占用事件预算，受预算上限约束
- Windows 交叉编译脚本未在作者之外的环境验证
- 深层嵌套子电路可能存在性能问题
